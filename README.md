# MessMate

A full-stack MERN platform connecting students with nearby mess/tiffin providers.

## Tech Stack
- Frontend: React, Vite, Tailwind CSS, React Router, Axios
- Backend: Node.js, Express, MongoDB Atlas, Mongoose
- Auth: JWT, bcrypt
- Media: Cloudinary

## Project Structure
- `/backend` — Express API
- `/frontend` — React client
